# ONG Miau-Noite — Plataforma Web Acessível

## 1. Apresentação do Projeto
Este projeto consiste no desenvolvimento da plataforma web para a ONG Miau-Noite, focado em promover a adoção responsável de animais e a captação de recursos. A aplicação foi projetada com total adesão às diretrizes de acessibilidade **WCAG 2.1 AA**, garantindo a inclusão de usuários com deficiências visuais, motoras ou cognitivas.

## 2. Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação semântica para navegação por leitores de tela e marcação de marcos de acessibilidade (`<header>`, `<main>`, `<nav>`, `<footer>`).
- **CSS3 & Atributos ARIA:** Estilização responsiva com foco em contraste cromático adequado e uso de papéis e estados ARIA (`aria-label`, `aria-expanded`).
- **Git & GitHub:** Versionamento de código utilizando a metodologia **GitFlow** e **Conventional Commits**.

## 3. Pré-requisitos
Para executar o projeto localmente, é necessário dispor de:
- Navegador web atualizado (Google Chrome, Mozilla Firefox, Microsoft Edge ou Safari).
- Editor de código (ex.: Visual Studio Code) com a extensão *Live Server* instalada.
- Leitor de tela para validação de acessibilidade (opcional, ex.: NVDA ou VoiceOver).
